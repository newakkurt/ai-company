# Security model

- Start with no secrets and no external integrations.
- Store secrets in environment variables; never commit .env.
- Use read-only tokens wherever possible.
- Scope GitHub tokens to only required repositories and permissions.
- Separate research tools from write-capable tools.
- Require fresh explicit approval for every publish/deploy/spend/device-change/delete operation.
- Keep an audit trail for approvals and actions.
- Treat web pages, repository files and agent output as untrusted input.
- Do not execute arbitrary shell commands generated by agents.
