# NetCmd PRO — MSP Discovery & Audit Qualification Pack

Date: 2026-11-11
Status: internal sales enablement draft; not sent to prospects.

## Ideal partner profile
- Managed IT / MSP / network integrator supporting multiple SMB customer sites.
- Supports one or more of Huawei, Cisco, Aruba, Fortinet, or mixed-vendor networks.
- Has recurring needs for configuration review, inventory, evidence collection, change documentation, or customer-facing audit reports.
- Can provide sanitized configuration snippets or read-only exports with customer authorization.

## Qualification questions
1. How many customer sites and network devices do you routinely support?
2. Which switch and firewall vendors appear most often?
3. How do you currently collect inventory and configuration evidence?
4. How long does a baseline network audit take per site?
5. Which recurring findings are hardest to document consistently?
6. Do customers request monthly/quarterly audit evidence?
7. Would a sample report using synthetic data be useful before a pilot?
8. Who approves security tooling and data processing?

## Pilot offer — draft only
A bounded evaluation can cover one site and up to 10 devices using customer-supplied, sanitized evidence. Deliverables: inventory summary, evidence-backed findings, risk-ranked remediation checklist, and a review call. No credentials, direct device connection, configuration changes, or production deployment are included in this draft.

The $69/month amount is a target hypothesis only; it is not an active subscription. Do not represent it as an active subscription until the Buy Me a Coffee tier, signed webhook, entitlement mapping, cancellation lifecycle, and a real test payment are verified.
