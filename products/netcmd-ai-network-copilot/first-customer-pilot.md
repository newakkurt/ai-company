# First Customer Pilot — NetCmd Network Audit

## What the customer receives

A bounded, read-only review of a small network environment, using customer-supplied and customer-approved evidence.

### Pilot scope

- One site
- Up to 10 network devices
- Huawei, Cisco and Aruba switch evidence
- Sanitized configuration excerpts and selected command outputs supplied by the customer
- No direct device connection and no production changes

Scope can be reduced or separately quoted if the evidence set or environment is larger.

## Deliverables

1. Device and interface inventory summary.
2. Evidence register with collection dates and source identifiers.
3. Findings table separating observed facts from assumptions.
4. Prioritized recommendations with rationale.
5. Coverage gaps and items marked **Not verified**.
6. Customer handover report in Markdown or PDF, as agreed.

## Delivery window

Target delivery: within 3 business days after scope approval and receipt of complete, readable evidence. The delivery window is confirmed in the written quote.

## Customer prerequisites

- Written confirmation that the customer owns or is authorized to share the supplied environment data.
- One named technical contact and one approval owner.
- Secrets removed from all configuration files and command output before transfer.
- Evidence transferred through a customer-approved private channel, not public GitHub or public AI prompts.

## Explicit exclusions

- No password, token, private-key, SNMP-community or personal-data collection.
- No penetration testing, exploit activity, vulnerability scanning, or device login.
- No configuration changes, interface shutdown/enablement, VLAN changes, restarts, or remediation.
- No guarantee that all risks will be found from partial evidence.
- No legal, regulatory or compliance certification.

Any remediation or implementation assistance requires a separate scope, quote, maintenance window, rollback plan and written customer approval.

## Commercial status

This document is a pilot offer outline, not a live checkout or binding contract. Price, seller details, invoice/tax handling, delivery terms and payment method must be confirmed in a written quote before acceptance. The USD 69/month NetCmd PRO target is separate and must not be represented as a live subscription until the membership tier and webhook/entitlement flow are verified.
